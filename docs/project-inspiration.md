# Project Inspiration

## Trends

- Editorial-style portfolio layouts combining typography and imagery
- Motion-led web design using subtle, purposeful animations (micro-interactions, scroll-based movement)
- Minimalist interfaces with strong visual hierarchy and negative space

## Visual References

- Contemporary designer portfolios that blend grid systems with expressive layouts
- Magazine and editorial spreads where images and text overlap in a controlled way
- Modern web design references featuring horizontal scrolling galleries and immersive navigation

## Theme Draft

This project explores the balance between **structure and expression** in digital portfolios.  
Using a clean Bootstrap-based layout as a foundation, the design introduces motion, layered imagery, and interactive elements to create a more personal and dynamic experience.

The goal is to present work not only as a collection of projects, but as a **visual narrative**, where layout, animation, and interaction reflect the designer’s identity and creative process.
